# Explainable-Machine-Learning-for-Parkinson-s-Disease-Classification-Using-Voice-Biomarkers

A machine learning research prototype that analyzes biomedical voice measurements to classify samples into **Healthy** and **Parkinson's** classes. The project combines **exploratory data analysis, statistical analysis, feature analysis, machine learning, model evaluation, and an interactive Streamlit application**.

> ⚠️ **Disclaimer:** This project is intended for educational and research purposes only. It is **not a medical diagnostic system** and should not be used for clinical decision-making.

---

## 📌 Project Overview

Parkinson's disease can affect speech and vocal characteristics. This project investigates whether measurable voice biomarkers can be used by machine learning models to distinguish between healthy individuals and individuals belonging to the Parkinson's class in the research dataset.

The project follows a complete machine learning workflow:

```text
Voice Dataset
      ↓
Data Cleaning
      ↓
Exploratory Data Analysis
      ↓
Statistical Analysis
      ↓
Feature Analysis
      ↓
Data Preprocessing
      ↓
Machine Learning
      ↓
Model Comparison
      ↓
Cross-Validation
      ↓
Explainable AI
      ↓
Streamlit Application
```

---

## 🎯 Objectives

The main objectives of this project are to:

* Analyze biomedical voice measurements.
* Explore differences between healthy and Parkinson's samples.
* Identify important voice-related features.
* Investigate correlations between voice biomarkers.
* Perform statistical analysis of selected features.
* Train multiple machine learning classifiers.
* Compare model performance using appropriate evaluation metrics.
* Investigate model predictions using explainable AI techniques.
* Develop an interactive Streamlit research prototype.

---

The project uses the **Parkinson's voice dataset**, which contains biomedical voice measurements extracted from voice recordings.
